\subsection{Database integration test}
Các test database được bật có điều kiện để tránh ghi vào production. Test chỉ chạy đầy đủ khi có \texttt{TEST\_DB=1} và cấu hình \texttt{TEST\_DATABASE\_URL} hoặc bộ biến \texttt{DB\_HOST}, \texttt{DB\_USER}, \texttt{DB\_NAME}. Workflow ghi dữ liệu chỉ chạy thêm khi bật \texttt{TEST\_DB\_WRITE=1}; dữ liệu expense tạo trong test được xóa ở bước cleanup.

\subsection{Lệnh chạy kiểm thử}
\begin{verbatim}
# Frontend
npm run test:ci

# Backend unit + HTTP integration
cd Backend-dacn
npm test

# Database integration, PowerShell
$env:TEST_DB='1'
$env:TEST_DB_WRITE='1'
$env:DB_HOST='localhost'
$env:DB_PORT='3307'
$env:DB_USER='root'
$env:DB_PASSWORD='your_password'
$env:DB_NAME='employee_management_db'
npm run test:db
\end{verbatim}

Không đặt thông tin production database vào môi trường test. Nên tạo database riêng, chạy schema và seed trước khi chạy \texttt{test:db}.

\subsection{Lỗi đã sửa}
\begin{itemize}
    \item Tách Express app khỏi \texttt{listen} để Supertest có thể import và kiểm thử.
    \item Sửa script backend để Node test runner nhận thư mục test trên Windows.
    \item Thêm \texttt{setupTests.js} cho matcher React Testing Library.
    \item Sửa assertion KPI bị trùng nhiều phần tử.
    \item Thêm validation và test cho KPI, summary chi phí và phân quyền.
    \item Thêm cleanup cho workflow expense integration có ghi dữ liệu.
\end{itemize}

\subsection{Kết luận}
Bộ test đã được xây dựng với 18 test case và cả 18 test đều đạt trên MySQL test instance riêng. Database integration test đã kiểm tra kết nối, dữ liệu KPI, chi phí, thời gian làm việc và workflow tạo/duyệt chi phí; dữ liệu ghi thử đã được cleanup. Frontend build và toàn bộ unit/HTTP test hiện có đều đạt.
